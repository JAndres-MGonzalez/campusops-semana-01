## Predicción

Las solicitudes simultáneas deben compartir una renovación y reintentarse una sola vez. Una respuesta del token anterior debe usar el token actualizado. Cerrar sesión debe eliminar el token y bloquear las consultas, incluso si una respuesta o escritura termina después.

## Explicación

Compartir la renovación evita pedir una sesión nueva por cada solicitud. Si otra solicitud ya renovó el token, se usa ese resultado. Al cerrar sesión se bloquean las consultas y se descartan las respuestas pendientes para que el usuario no vuelva a quedar conectado.
